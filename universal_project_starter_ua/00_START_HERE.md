# 00_START_HERE

Це стартовий набір універсальних файлів для нового програмного проєкту.

Його мета - допомогти вам і AI-асистенту не починати з хаотичного написання коду, а спочатку зрозуміти продукт, вимоги, архітектуру, ризики, тести, деплой і план розвитку.

## Як використовувати

1. Скопіюйте всі файли в корінь нового проєкту.
2. Заповніть `PROJECT.md`, `REQUIREMENTS.md` і `AI_WORKFLOW.md` перед написанням коду.
3. Для першого запуску великого проєкту використайте `FULL_START_PROMPT_FOR_AI.md`.
4. Для короткого нагадування AI-асистенту використайте `START_PROMPT_FOR_AI.md`.
5. Або дайте AI-асистенту мінімальну інструкцію:

```text
Прочитай файли PROJECT.md, AI_WORKFLOW.md, REQUIREMENTS.md, ARCHITECTURE.md, TASKS.md і не пиши код, поки не сформуєш план та не отримаєш моє підтвердження.
```

6. Після кожної задачі оновлюйте:

- `CHANGELOG.md`;
- `TASKS.md`;
- `TESTING.md`;
- `DECISIONS.md`, якщо було прийнято важливе рішення;
- `BACKLOG.md`, якщо зʼявилися ідеї не для MVP.

## Для чого кожен файл

- `README.md` - короткий опис проєкту та інструкція запуску.
- `START_PROMPT_FOR_AI.md` - короткий prompt для старту або повернення AI до правил.
- `FULL_START_PROMPT_FOR_AI.md` - повний універсальний prompt для початку нового проєкту.
- `PROJECT.md` - головна карта проєкту: ціль, MVP, success criteria.
- `AI_WORKFLOW.md` - правила роботи AI-асистента.
- `REQUIREMENTS.md` - функціональні й нефункціональні вимоги.
- `ARCHITECTURE.md` - компоненти, data flow, інтеграції, база даних.
- `TASKS.md` - маленькі задачі для реалізації.
- `BACKLOG.md` - ідеї, які не входять у MVP.
- `ROADMAP.md` - розвиток по версіях.
- `DECISIONS.md` - важливі технічні й продуктові рішення.
- `TESTING.md` - позитивні, негативні й edge-case сценарії.
- `SECURITY_PRIVACY.md` - секрети, персональні дані, приватність.
- `ENVIRONMENT.md` - змінні середовища та локальні налаштування.
- `.env.example` - приклад змінних середовища без реальних секретів.
- `DEPLOYMENT.md` - як запустити проєкт у production.
- `CHANGELOG.md` - історія змін.

## Головне правило

Не починайте з коду.

Спочатку:

```text
Idea -> Discovery -> Requirements -> Technology Choice -> Architecture -> Tasks -> Implementation -> Review -> Testing -> Documentation
```
