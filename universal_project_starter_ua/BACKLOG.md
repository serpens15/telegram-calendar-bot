# BACKLOG

Backlog містить ідеї, які корисні, але не входять у поточний MVP.

AI не має реалізовувати backlog без окремого підтвердження користувача.

## Future Features

```text
- [ ] Feature:
  Value:
  Why not MVP:
```

## Premium Ideas

```text
- [ ] Premium feature:

  Complexity:
```

## Technical Improvements

```text
- [ ] Improvement:

  Risk if ignored:
```

## Risks to Revisit


## Later / Maybe
