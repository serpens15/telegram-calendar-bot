## Regression Checklist

Перед релізом перевірити:

- [ ] Основний сценарій працює.
- [ ] Некоректний input не ламає систему.
- [ ] Секрети не потрапили в код.
- [ ] Документація актуальна.
- [ ] Немає Critical/High bugs.
